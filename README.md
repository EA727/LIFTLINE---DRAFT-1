# LiftLine

Working prototype of LiftLine, a campus fitness and nutrition app piloting at UTSA.

Demo login: Test@Mail.com / TESTING123

## Put it online with GitHub Pages

1. Create a new repository on GitHub (for example `liftline`). Public repositories get free Pages hosting.
2. Upload every file in this folder to the root of the repository (Add file > Upload files), then commit.
3. Open Settings > Pages. Under "Build and deployment", set Source to "Deploy from a branch", choose `main` and `/ (root)`, and save.
4. After a minute or two the site is live at `https://YOUR-USERNAME.github.io/liftline/`.

## Add it to a phone home screen

Open the link in Safari (iPhone) or Chrome (Android), then use Share > Add to Home Screen. It opens full screen like an app.

## Notes

- The app remembers where you left off on each device. Add `?reset` to the end of the link to start the demo over.
- `app.js` holds the screens' logic and data, `index.html` holds the layout and styles, and `runtime.js` is the small engine that draws it.
